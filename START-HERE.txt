منصة أ/ عمرو موسى — النسخة المجهزة للنشر

1) فك الضغط وافتح مجلد المشروع في VS Code.
2) انسخ .env.example إلى ملف باسم .env.
3) ضع قيم قاعدة البيانات و AUTH_SECRET ومتغيرات WhatsApp المطلوبة في بيئة التشغيل.
4) نفّذ:
   npm install
5) بعد انتهاء التثبيت نفّذ:
   npx prisma generate
6) افحص المشروع:
   npm run lint
   npx tsc --noEmit
   npm run build
7) شغّل المنصة محليًا:
   npm run dev
8) افتح:
   http://localhost:3000

متغيرات مهمة:
- DATABASE_URL: اتصال قاعدة البيانات المستخدم وقت التشغيل.
- DIRECT_URL: اتصال مباشر يستخدمه Prisma عند الحاجة.
- AUTH_SECRET: سر قوي لـ NextAuth.
- NEXT_PUBLIC_TEACHER_WHATSAPP: رقم WhatsApp بصيغة دولية بدون + أو مسافات، مثل 201274561940.
- AI_API_KEY: مفتاح مزود الذكاء الاصطناعي. لا تضعه في Git.
- AI_BASE_URL: افتراضيًا https://api.openai.com/v1.
- AI_MODEL: اسم النموذج الذي يوفره مزودك.

الاشتراكات:
- الطالب يختار الخطة.
- زر «الحصول على الكود عبر واتساب» يفتح رسالة جاهزة للمدرس بالخطة والسعر.
- المدرس ينشئ الكود من لوحة الإدارة.
- الطالب يفعّل الكود داخل المنصة.
- السعر ومدة الاشتراك يتحكمان بهما من لوحة الإدارة.

الإدارة:
- لوحة الإدارة تحتوي على مركز تحكم للمحتوى لإضافة الكورسات والوحدات والمحاضرات والفيديوهات والملفات والواجبات والاختبارات والأسئلة ونشرها أو إخفائها.
- رفع الفيديو كملف فعلي يحتاج تخزينًا خارجيًا مناسبًا للاستضافة؛ حاليًا مركز المحتوى يقبل رابط الفيديو/الملف حتى لا يتم تخزين الملفات الكبيرة داخل قاعدة البيانات.

الأمان:
- لا ترفع ملف .env إلى GitHub.
- لا تضع AUTH_SECRET أو AI_API_KEY داخل الكود.
- حساب الأدمن يجب أن يكون موجودًا في قاعدة البيانات، وتبقى بيانات دخوله سرية.
